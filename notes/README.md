# notes/ — dated + signed notes

Convention (see PROJECT-STANDARD.md in AIShare):

- Filename: `YYYY-MM-DD-<author>.md`
- Header: `Author:` / `Date:` / `Project:`
- Content: learned things, decisions, blocks — facts, not chat logs
- Review: when STATUS.md is refreshed (or at least monthly), update stale
  notes, delete wrong ones, sign the review.
