External display plug -> desktop freeze.  ASUS Zenbook A16 (UX3607OA), 2026-09-17.
Kernel 7.3.0-rc3-next-20260914, booted via the drm.debug=0x1ff debug entry.

The monitor went on the USB-C port (USB-C DP alt-mode, DRM connector card1-DP-2).  The screen froze
and the machine was power-cycled.  Extracted from the journal of the freeze boot -- the previous
boot, whose entries run 09:08-10:45 on 2026-09-17 -- and from the boot after it.  DRM ioctl tracing
was on for the freeze boot, so its raw journal is 7.6 million lines; DRM_IOCTL_WAIT_VBLANK,
"Missed N kernel messages", the module list and the register dump are dropped here.

Timeline of the freeze (all 2026-09-17):
  10:44:42  the dock/monitor's USB hub enumerates on the USB-C port
  10:44:43  MSI monitor's USB device + its usb-storage interface; sdb read errors
  10:44:44  ucsi reports the partner's alt-mode list as malformed (29 x duplicate DP SVID)
  10:44:45.733  DP-2 output enable starts: rate=810000, 4 lanes
  10:44:45.744  disp_cc_mdss_dptx1_link_clk -- status stuck at 'off' -> -EBUSY
  10:44:45.745  DP prepare fails, rc=-16
  10:44:46 - 10:44:54  the atomic commit never completes: vblank timeout, frame done timeout
  10:45:07  USB bus 3 deregistered
